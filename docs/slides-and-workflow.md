### Q&A 预案（先备着，答辩前扩成完整清单）

| 可能被问 | 一句话回答方向 |
|---|---|
| 为什么不随机切分？ | 真实用法是用过去预测未来；随机切分会「见过未来」，虚高 |
| 标签为什么是 ROA 下滑而不是薪酬过高？ | 薪酬是否过高无法客观定义；业绩下滑是可观测的审查触发信号，模型只建议审查 |
| 没有行业码怎么办？ | 全样本分位数替代 + 替代定义稳健性检验（§4） |
| 模型黑箱委员会敢用吗？ | 主对比含逻辑回归（系数可读）；RF 提供 lift；政策上有人工核查兜底 |
| 样本这么小结论可信吗？ | 定位是辅助排序工具；报告校准图与 limitations 如实呈现 |

## 审查工作流（两张图，做 PPT 前先画进 `docs/assets/`）

**图 1 · 分析管线（P3 用）**

```
Firm_CEO_Compensation ─┐
                       ├─ GVKEY+YEAR 合并 ─ 筛 CEO(ceoann) ─ t/t+1 对齐
Firm_Information ──────┘
        │
        ▼
  特征（只用 t 年：薪酬水平与结构/规模/ROA/杠杆/成长/前期业绩）
        │                                    ┌─ 主定义：ROA 下降最差 20% 分位
        ▼                                    ├─ 替代 A：最差 25% 分位
  打分卡 │ 逻辑回归 │ 随机森林 ─ 时间切分评估 ─┤
        │                                    └─ 替代 B：固定阈值下降
        ▼
  风险分排序 → 审查清单（top-k）
```

**图 2 · 委员会两段式工作流（P10 用，核心卖点）**

```
全部 firm-year 薪酬包
        │
        ▼
  ┌─────────────┐
  │ AI 模型排序  │  → 输出风险分 top-k（建议容量：每年审 k 家）
  └─────────────┘
        │
        ▼
  ┌─────────────────────────────┐
  │ 人工核查三步（模型不做判断）  │
  │ ① 一次性事件？(重组/减记)     │
  │ ② 行业整体冲击？             │
  │ ③ 合同细节？(新授予 vs 归属)  │
  └─────────────────────────────┘
        │
        ▼
  进入正式审查 / 放行（决定权永远在人）
```
